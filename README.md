Number Guessing Game 🎯
A simple Java console-based Number Guessing Game where the computer generates a random number between 1 and 10, and the player gets 5 attempts to guess it correctly.

📌 Features
Generates a random number between 1 and 10.

Gives the player 5 attempts to guess the number.

Provides feedback after each incorrect guess.

Displays a congratulatory message when the player guesses correctly.

Reveals the correct number when all attempts are used.

🛠️ Technologies Used
Java

Scanner — for reading user input.

Random — for generating the random number.

🎮 How to Play
Run the NumberGuessingGame program.

The computer generates a random number from 1 to 10.

Enter your guess when prompted.

You have 5 attempts to guess the correct number.

If your guess is correct, you win!

If all attempts are used, the game reveals the correct number.
